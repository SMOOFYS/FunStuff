# CISP 440 – Discrete Structures for Computer Science

Programming assignments from CISP 440 (Spring 2026).

| # | Assignment | Language | What it does |
|---|---|---|---|
| 1.42 | [Set Implementation](01_Set_Implementation) | C | Set operations (union, intersection, difference, complement, power set) using bit vectors |
| 2.42 | [Sequences and Substrings](02_Sequences_and_Substrings) | C | Five programs exploring sequences, sums and substrings |
| 4.42 | [Floating Point](04_Floating_Point) | C | 8-bit floating point addition and multiplication using only integer operations |
| 5.42 | [Relations](05_Relations) | C | Checks whether a relation matrix is reflexive, symmetric or transitive, and lists equivalence classes |
| 8.42 | [Logical Equivalence](08_Logical_Equivalence) | C | Builds truth tables to test whether pairs of logical expressions are equivalent |
| 10.42 | [State Table Generator](10_State_Table_Generator) | C | Builds a finite-state machine for a pattern and uses it to search text |
| 12.42 | [Natural Language Generator](12_Natural_Language_Generator) | C++ | Generates random sentences from context-free grammars |

Build any of them with `gcc file.c -o program` (or `g++` for the `.cpp` one).
Relations and State Table Generator read input files from the class that aren't included here.
